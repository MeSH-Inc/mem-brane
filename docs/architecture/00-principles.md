# mem-brane principles

mem-brane is a spatial thinking interface: a brane organizes text, images, imported webpages and model responses. Brane is the product's page primitive, including application types, routes and SQL names.

This is a spatial thinking interface, not a workflow engine.

Spatial arrangement is presentation. Context relationships are semantics.

Live collaborative state and historical model context are separate concepts.

Moving a card never changes context. Connecting, grouping or proximity never executes anything. Only an explicit Run action incurs model cost. Stable application IDs survive transport, rendering and future collaboration engines. Start with one Node process, SQLite WAL, object storage and Caddy. Keep mutable state replaceable without general frameworks, event sourcing or speculative distributed infrastructure.
