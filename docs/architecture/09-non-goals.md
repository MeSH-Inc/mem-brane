# Non-goals

Deferred: multiplayer implementation, realtime cursors, CRDTs, WebSockets, conflict-resolution UI, collaborative awareness, rich text, vector databases, embeddings, semantic retrieval, workflow execution, automatic downstream execution, automatic regeneration, general DAG semantics, plugin frameworks, headless crawling, mobile canvas-editing parity, multi-server workers and multi-region architecture.

This is a concrete single-server product scaffold. Greenfield development favors correcting boundaries directly rather than preserving accidental compatibility.
